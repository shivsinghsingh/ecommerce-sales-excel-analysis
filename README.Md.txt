# E-Commerce Sales Analysis – Excel Dashboard

## 📌 Project Overview

This project analyzes E-Commerce sales data using Microsoft Excel.

The project focuses on sales performance, profit, orders, product performance, customer locations, payment modes, discounts, and order status.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- XLOOKUP
- IF
- IFS
- UNIQUE
- SUMIF
- COUNTIF
- AVERAGEIF
- COUNTIFS

## 📊 Dataset

The dataset contains 500 E-Commerce orders with the following columns:

- Order ID
- Order Date
- Customer Name
- City
- Category
- Product Name
- Quantity
- Unit Price
- Discount
- Payment Mode
- Order Status
- Sales Amount
- Profit

## 📈 Dashboard KPIs

- Total Sales
- Total Orders
- Total Quantity
- Average Order Value

## 📊 Analysis Performed

- Category-wise Sales
- Category-wise Profit
- Order Status Analysis
- Payment Mode Analysis
- Monthly Sales Trend
- Top 5 Products by Sales
- City-wise Sales
- Discount Analysis
- Profit by Order Status
- Category-wise Quantity Sold
